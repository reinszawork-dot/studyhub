# StudyHub

A student productivity website: a dashboard, study analytics, a Pomodoro timer, tasks, a calendar, notes, subjects, goals and achievements.

- Plain HTML, CSS and JavaScript with no build step. Charts use Chart.js.
- Data is saved in the browser (localStorage). You can export and import backups from Settings.
- Colour palettes: Teal & mint and Forest & sage, each in light and dark mode.
- Installable as an app (PWA), and works offline after the first visit.

Run it locally by serving the folder with any static server, for example `npx serve .`.
